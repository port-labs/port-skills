# Contributing a skill

The authoring guide, frontmatter spec, and validation tooling for this repo
now live in [`skills/port-skill-creator/SKILL.md`](skills/port-skill-creator/SKILL.md)
(and its `references/skill-writing-guide.md`), it's a skill in its own right:
point your coding agent at it and ask it to help you write a new skill for
this repo.

Quick links:

- Format and body structure: [`skills/port-skill-creator/SKILL.md`](skills/port-skill-creator/SKILL.md)
- Full writing guide: [`skills/port-skill-creator/references/skill-writing-guide.md`](skills/port-skill-creator/references/skill-writing-guide.md)
- Validator: `node skills/port-skill-creator/scripts/validate-skill.js skills/port-<your-skill>`
- Regenerate the README index: `node skills/port-skill-creator/scripts/generate-skill-index.js`
